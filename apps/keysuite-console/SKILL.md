# KeySuite

Shell the local runtime. Treat `receipt` as the only executable descriptor.

```bash
node --experimental-strip-types --test src/lib/gdk9/gdk9.test.ts
```

Canonical example:

```
tokens: C C . 3 3 SPACE
receipt: CC→33
grammar: gdk9-v1.1.0.yaml
sha256: 0c8974e76427799dc62ac6839057c8fff41d3ad7ae29c3e6c9d070dd9df1b7a7
```

Do not invent a second reducer. Session is the only module that calls ρ. MODE+BIND is out of scope.
